# 碑帖拓片版本比对台

`sologsb-1020` 是一个本地优先的碑帖拓片版本回传对账工作台，使用 Qwik、TypeScript 与 Qwik UI 构建。外场编目组按拓片号、摹刻批次、原石和扫描指纹登记版本比对包，本机版本比对台负责把外场回传挂回原记录、合并结论、字段选择与审计。

## 对账规则（核心需求）

1. **稳定编号挂回**：只按拓片号（`stableId`）挂接；本机编号可改，但稳定编号永不变，改过编号也不会错配。包内出现的外场/曾用编号自动并入 `aliases` 备查。
2. **分歧并列保留**：纸张、拓工、钤印三项出现不同说法时，全部来源值并列保存在字段 `variants` 中并生成「待裁项」，确认前不覆盖任何值。
3. **确认后受保护**：待裁项一经裁定即写入 `chosen` 并锁定；此后任何回传的不同取值都被挡下（`blockedFields`）并写审计，绝不覆盖已确认结果。落选候选仍留档。
4. **写入中断可续传**：每条包条目按 `包号:条目号` 落盘登记。中断后保留已处理进度（批次 `finishedAt` 为空），选择同一包即可从断点续传。
5. **重试幂等不重复建档**：同一包重复导入，已处理条目全部跳过，不会重复建立拓片档。
6. **旧版包兼容**：无版本号、中文键名（拓片号/名称/摹刻批次/原石/纸张/拓工/钤印）、缺扫描指纹的旧包自动归一化迁移导入。
7. **待裁项清零才导出**：仍有未裁定项时导出按钮被阻塞；处理完后才能更新导出回执包，回执含全部字段确认值、裁定记录与审计轨迹。
8. **扫描指纹只核对**：指纹不一致仅作提示（`fingerprintMismatch`），不改写本机数据。

## 功能

- 回传导入弹窗：解析预览包号/版本/条目，逐条标注「已导入·跳过 / 将挂回 / 将新建档」，并提供「模拟写入中断」开关用于验证续传。
- 待裁项队列：J/K 移动、X 打开裁定，支持多选批量取首项确认。
- 拓片台账：稳定编号、本机编号（可改）、曾用编号别名、摹刻批次、原石、指纹与三字段并列/确认状态，分批窗口渲染。
- 裁定弹窗：选择并列候选或另填裁定值；已锁定字段禁止改判（需先撤销）。
- 导入履历：每个包的版本、进度条、完成/中断状态。
- 审计轨迹：导入、挂回、新建、字段受保护、裁定、改编号、导出全程留痕；支持撤销/重做与 localStorage 离线保存。

## 开发

```bash
npm install
npm run dev
```

## 校验

```bash
npm run verify     # 对账核心逻辑：31 项断言（挂接/并列/保护/中断续传/幂等/旧包/改编号）
npm run smoke:ssr  # 成对构建 SSR 产物并断言关键内容渲染、QRL 全部可序列化
npm run build      # tsc 类型检查 + 生产构建
```

外场样本包位于 `public/samples/`：

- `waihui-bidui-v2.json`：当前版本包，含本机改编号后用旧号回传、同一拓片号两条不同编号登记、指纹不一致、新建档等情形。
- `waihui-bidui-legacy-v1.json`：中文键名、无版本号的旧版包。

## 技术栈

- Qwik 1.20 · TypeScript 5.9 · Qwik UI Headless · Vite 7
- 纯前端本地优先，数据保存在当前浏览器 `localStorage`，不会自动确认或覆盖任何已确认字段。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```
